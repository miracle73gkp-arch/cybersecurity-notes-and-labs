Hello World Program

Purpose

This is my first C++ program in this repository. It demonstrates the basic structure of a C++ program and prints a message to the console.

Concepts Used

- "#include <iostream>" — provides input/output functionality.
- "using namespace std;" — allows standard library names such as "cout" to be used without the "std::" prefix.
- "main()" — the entry point of the program.
- "cout" — displays output on the screen.
- "return 0;" — indicates that the program finished successfully.

Output

Hello, Cybersecurity!
